# /setup buttons

Setup buttons for the server.

{% hint style="info" %}
For setup steps and examples, read [How to Set Up ClashPerk on Discord](../../../overview/getting-set-up.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `button_type` | Text | Select the button type to setup<details><summary>View Options</summary>`Link Button`, `Role Refresh Button`, `My Rosters Button`</details> |
| `embed_color` | Text | Hex color code for the embed |

## Related commands

* [/setup clan](clan.md): Link/unlink clans to the server or channels.
* [/setup clan-embed](clan-embed.md): Enable/disable clan embed on the server or add/remove clans.
* [/setup clan-logs](clan-logs.md): Setup automatic logs for the clan.
* [/setup events](events.md): Setup automatic events for the server.
* [/setup list](list.md): List all enabled features and clans.
* [/setup server-logs](server-logs.md): Setup automatic logs for the server.
