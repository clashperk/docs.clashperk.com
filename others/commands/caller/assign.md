# /caller assign

Set a target for a player in the current war.

## Options

| Name | Type | Description |
|------|------|-------------|
| `defense_target` | Whole number | The base target # of your opponent. |
| `offense_target` | Whole number | The base target # of your clan. |
| `notes` | Text | Notes to add to the target. |
| `hours` | Number | The number of hours to set the target for. |

## Related commands

* [/caller clear](clear.md): Clear the target for a player in the current war.
