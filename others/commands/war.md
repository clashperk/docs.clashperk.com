# /war

Shows war summary and overview of a clan.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `user` | User | Clan by @user mention or ID. |
| `war_id` | Text | Search by war ID. |
