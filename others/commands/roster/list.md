# /roster list

Search rosters or list all rosters and groups.

{% hint style="info" %}
For setup steps and examples, read [CWL and War Rosters](../../../features/rosters/README.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `name` | Text | Search rosters by name |
| `user` | User | Search rosters by user |
| `player` | Text | Search rosters by player |
| `clan` | Text | Search rosters by clan |
| `category` | Text | Search rosters by category<details><summary>View Options</summary>`CWL`, `WAR`, `E-SPORTS`, `TROPHY`, `Un-categorized`</details> |
