# /export capital-raids

Export capital raid attack stats.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases to filter clans. |
| `limit` | Whole number | Number of raid weekends (Default: 4) |
