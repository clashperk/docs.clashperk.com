# /roster groups modify

Modify or delete a group.

{% hint style="info" %}
For setup steps and examples, read [CWL and War Rosters](../../../features/rosters/README.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `group` | Text | Select a group to modify |
| `name` | Text | Name of the group |
| `order` | Whole number | Order of the group |
| `group_role` | Role | Role of the group |
| `selectable` | True or False | Whether to allow members to select this group |
| `delete_role` | True or False | Whether to delete the role of the group |
| `delete_group` | True or False | Whether to delete the group |
