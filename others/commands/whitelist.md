# /whitelist

Whitelist a role or user to use specific commands.

{% hint style="info" %}
For setup steps and examples, read [Whitelist](../whitelist.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `user_or_role` | User or role | User or role to whitelist. |
| `command` | Text | Command to whitelist. |
| `clear` | True or False | Clear the whitelist. |
| `list` | True or False | List all whitelisted users and roles. |
