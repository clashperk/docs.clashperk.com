# /autorole refresh

Refresh roles manually. (Use this command if the roles are not updated automatically)

{% hint style="info" %}
For setup steps and examples, read [Auto Roles for Clan Role, Town Hall and League](../../../features/auto-role.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `user_or_role` | User or role | Refresh an individual user or a role. |
| `is_test_run` | True or False | Test run to see the changes without applying. |
| `force_refresh` | True or False | Whether to bypass delays and force refresh roles. |
