# /link create

Links a player account/clan to a Discord account.

{% hint style="info" %}
For setup steps and examples, read [Link and Verify Clash of Clans Accounts](../../../overview/link-account.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `player_tag` | Text | The player tag to link. |
| `clan_tag` | Text | The default clan tag to link. |
| `user` | User | User account to link to the tag. |
| `is_default` | Text | Whether to set this as the default account. |

## Related commands

* [/link delete](delete.md): Deletes a player account/clan from a Discord account.
* [/link list](list.md): List all player links of a clan.
