# /roster clone

Clone a roster to create a new one.

{% hint style="info" %}
For setup steps and examples, read [CWL and War Rosters](../../../features/rosters/README.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `roster` | Text | Select a roster to clone |
| `name` | Text | Name of the cloned roster |
