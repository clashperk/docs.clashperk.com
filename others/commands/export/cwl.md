# export cwl

Export CWL stats to Excel.

## Options

| Name | Description |
|------|-------------|
| `clans` | Clan tags or aliases to filter clans. |
| `season` | Retrieve data since the specified season.<details><summary>View Options</summary>`Oct 2026`, `Sep 2026`, `Aug 2026`, `Jul 2026`, `Jun 16, 2026`, `Jun 2026`, `May 2026`, `Apr 2026`, `Mar 2026`, `Feb 2026`, `Jan 2026`, `Dec 2025`, `Nov 2025`</details> |
| `lineup_only` | Export only the lineup. |
