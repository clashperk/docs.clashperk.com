# /rushed

Rushed units and rushed % of a player or clan members.

## Options

| Name | Type | Description |
|------|------|-------------|
| `player` | Text | Player tag or name. |
| `user` | User | Player by @user mention or ID. |
| `clan` | Text | Displays rushed units of a clan. |
