# Commands

ClashPerk works through Discord slash commands. Type `/` in a channel ClashPerk can see, then pick a command. New to the bot? Start with [How to Set Up ClashPerk on Discord](../../overview/getting-set-up.md).

## Command groups

| Group | What it's for |
|-------|---------------|
| [/alias](alias/README.md) | Give your clans short names, so you can type an alias instead of a clan tag. |
| [/autorole](autorole/README.md) | Give Discord roles automatically from members' clan roles, Town Halls, leagues and wars. |
| [/caller](caller/README.md) | Call war targets, so clan members know which base each player will attack. |
| [/capital](capital/README.md) | See clan capital contributions and raid weekend scores of your clan members. |
| [/category](category/README.md) | Group the clans linked to your server into named categories. |
| [/cwl](cwl/README.md) | Clan War League stats for your clan: lineups, attacks, stars, rounds and group standings. |
| [/export](export/README.md) | Export clan, war, CWL, capital and roster stats to a spreadsheet. |
| [/flag](flag/README.md) | Mark players as banned or flagged, and list or remove those flags. |
| [/giveaway](giveaway/README.md) | Run giveaways with an Enter button, then draw, reroll or cancel them. |
| [/layout](layout/README.md) | Post village layouts to share them, and choose how layout posts work on your server. |
| [/leaderboard](leaderboard/README.md) | Top clan, player and clan capital leaderboards. |
| [/legend](legend/README.md) | Legend League attacks per day, leaderboards and trophy stats. |
| [/link](link/README.md) | Link Clash of Clans player accounts and clans to Discord users, and list or remove links. |
| [/nickname](nickname/README.md) | Set Discord nicknames automatically from members' linked accounts. |
| [/reminders](reminders/README.md) | Remind members who still have war attacks, raid attacks or Clan Games points left. |
| [/roster](roster/README.md) | Run CWL and war signup rosters: create and post them, manage members and groups, and ping them. |
| [/setup](setup/README.md) | Set up ClashPerk on your server: link clans, and turn on logs, buttons and events. |
| [/stats](stats/README.md) | Attack success and defense failure rates of your clan members. |
| [/summary](summary/README.md) | Summaries across every clan linked to your server: wars, CWL, donations, activity, capital and more. |
| [/ticket](ticket/README.md) | Set up ticket panels and manage ticket channels for applications and support. |
