# /setup server-logs

Setup automatic logs for the server.

{% hint style="info" %}
For setup steps and examples, read [Clan, War and Capital Logs](../../../features/logs.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `log_type` | Text | Select the log type to setup.<details><summary>View Options</summary>`Flag Alert Log`, `Roster Change Log`, `Maintenance Break Log`, `Welcome Log`</details> |
| `disable` | Text | Whether to disable the log. |
