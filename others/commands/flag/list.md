# /flag list

List all player flags.

{% hint style="info" %}
For setup steps and examples, read [Flags (Ban/Strike)](../../../features/flags-ban-strike.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `flag_type` | Text | The type of the flag (ban or strike)<details><summary>View Options</summary>`Ban`, `Strike`</details> |
| `player` | Text | Show all flags against a player |
| `clans` | Text | Clan tags or aliases to filter clans. |

## Related commands

* [/flag create](create.md): Create a player flag to mark the player as banned or flagged.
* [/flag delete](delete.md): Delete a player flag.
