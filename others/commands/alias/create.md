# /alias create

Creates a clan alias (short code or abbreviation) or clan nickname.

{% hint style="info" %}
For setup steps and examples, read [Clan Alias](../../../features/clan-alias.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `alias_name` | Text | Name of the alias. |
| `clan_nickname` | Text | Nickname of the clan (Experimental) |

## Related commands

* [/alias delete](delete.md): Deletes a clan alias.
* [/alias list](list.md): List all clan aliases.
