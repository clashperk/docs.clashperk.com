# /members

List clan members sorted by heroes, trophies, war preferences, discord links, clan roles, player tags, attacks, etc.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `user` | User | Clan by @user mention or ID. |
| `option` | Text | Select an option<details><summary>View Options</summary>`Heroes/War Weight`, `Discord Links`, `War Preferences`, `Player Tags and Roles`, `Trophies and Leagues`, `Last Joining Date`, `Player Progress`, `Attacks & Defenses`, `Clan Overview`</details> |
