# /link

Link Clash of Clans player accounts and clans to Discord users, and list or remove links.

{% hint style="info" %}
For setup steps and examples, read [Link and Verify Clash of Clans Accounts](../../../overview/link-account.md).
{% endhint %}

| Command | What it does |
|---------|--------------|
| [/link create](create.md) | Links a player account/clan to a Discord account. |
| [/link delete](delete.md) | Deletes a player account/clan from a Discord account. |
| [/link list](list.md) | List all player links of a clan. |
