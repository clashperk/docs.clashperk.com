# /setup list

List all enabled features and clans.

{% hint style="info" %}
For setup steps and examples, read [How to Set Up ClashPerk on Discord](../../../overview/getting-set-up.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Select the clans to list. |

* [/setup buttons](buttons.md): Setup buttons for the server.

* [/setup clan-embed](clan-embed.md): Enable/disable clan embed on the server or add/remove clans.
* [/setup clan-logs](clan-logs.md): Setup automatic logs for the clan.
* [/setup events](events.md): Setup automatic events for the server.
