# /legend days

Shows per-day legend attacks for a player.

## Options

| Name | Type | Description |
|------|------|-------------|
| `player` | Text | Player by @user mention or ID. |
| `user` | User | Clan by @user mention or ID. |
| `day` | Number | The league day. |

## Related commands

* [/legend attacks](attacks.md): Shows per-day legend attacks for a clan.
* [/legend leaderboard](leaderboard.md): Shows legend leaderboard.
* [/legend stats](stats.md): Shows statistics of legend ranks and trophies.
