# /legend stats

Shows statistics of legend ranks and trophies.

## Options

| Name | Type | Description |
|------|------|-------------|
| `reference_date` | Text | The date to view the end-of-day thresholds (YYYY-MM-DD) |

## Related commands

* [/legend attacks](attacks.md): Shows per-day legend attacks for a clan.
* [/legend days](days.md): Shows per-day legend attacks for a player.
* [/legend leaderboard](leaderboard.md): Shows legend leaderboard.
