# /setup clan-embed

Enable/disable clan embed on the server or add/remove clans.

{% hint style="info" %}
For setup steps and examples, read [How to Set Up ClashPerk on Discord](../../../overview/getting-set-up.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `channel` | Channel | Channel to send updates to (defaults to the current channel) |
| `color` | Text | Hex color code for the embed (for donation log, clan games, last seen, etc) |
| `disable_embed` | True or False | Disable clan embed. |
