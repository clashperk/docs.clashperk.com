# /capital raids

Shows raid weekend scores of clan members.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `user` | User | Clan by @user mention or ID. |
| `week` | Text | Retrieve data for the specified raid weekend.<details><summary>View Options</summary>`13 Nov, 2026`, `06 Nov, 2026`, `30 Oct, 2026`, `23 Oct, 2026`, `16 Oct, 2026`, `09 Oct, 2026`</details> |

## Related commands

* [/capital contribution](contribution.md): Shows clan capital contribution of clan members.
