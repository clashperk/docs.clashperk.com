# /export members

Export a comprehensive version of clan member stats.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases to filter clans. |
| `auto_export_on` | True or False | Whether to schedule the export to run every Sunday at 4:55 UTC. |
