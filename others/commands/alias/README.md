# /alias

Give your clans short names, so you can type an alias instead of a clan tag.

{% hint style="info" %}
For setup steps and examples, read [Clan Alias](../../../features/clan-alias.md).
{% endhint %}

| Command | What it does |
|---------|--------------|
| [/alias create](create.md) | Creates a clan alias (short code or abbreviation) or clan nickname. |
| [/alias delete](delete.md) | Deletes a clan alias. |
| [/alias list](list.md) | List all clan aliases. |
