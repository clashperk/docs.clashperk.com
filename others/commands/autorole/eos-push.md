# /autorole eos-push

Set end of season push roles.

{% hint style="info" %}
For setup steps and examples, read [Auto Roles for Clan Role, Town Hall and League](../../../features/auto-role.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `role` | Role | The end of season push role. |
| `clans` | Text | The clans for which to set the end of season push role. |
