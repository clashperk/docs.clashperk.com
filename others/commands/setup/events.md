# /setup events

Setup automatic events for the server.

{% hint style="info" %}
For setup steps and examples, read [Discord Events](../../../features/discord-events.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `disable` | Text | Disable the events schedular. |
