# summary capital-raids

Shows information about capital raids.

## Options

| Name | Description |
|------|-------------|
| `clans` | Clan tag or name or alias. |
| `week` | Retrieve data for the specified raid weekend.<details><summary>View Options</summary>`19 Jun, 2026`, `12 Jun, 2026`, `05 Jun, 2026`, `29 May, 2026`, `22 May, 2026`, `15 May, 2026`</details> |
