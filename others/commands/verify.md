# /verify

Verify and link a player account using an API token.

{% hint style="info" %}
For setup steps and examples, read [Link and Verify Clash of Clans Accounts](../../overview/link-account.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `player` | Text | Tag of the player to verify. |
| `token` | Text | API token that can be found in the game settings. |
