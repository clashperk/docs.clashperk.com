# /category

Group the clans linked to your server into named categories.

{% hint style="info" %}
For setup steps and examples, read [Clan Categories](../../../features/clan-categories.md).
{% endhint %}

| Command | What it does |
|---------|--------------|
| [/category create](create.md) | Create a new clan category. |
| [/category delete](delete.md) | Delete a clan category. |
| [/category edit](edit.md) | Edit a clan category. |
| [/category list](list.md) | List all clan categories. |
