# /caller

Call war targets, so clan members know which base each player will attack.

| Command | What it does |
|---------|--------------|
| [/caller assign](assign.md) | Set a target for a player in the current war. |
| [/caller clear](clear.md) | Clear the target for a player in the current war. |
