# /caller clear

Clear the target for a player in the current war.

## Options

| Name | Type | Description |
|------|------|-------------|
| `defense_target` | Number | The base target # of your opponent. |

## Related commands

* [/caller assign](assign.md): Set a target for a player in the current war.
