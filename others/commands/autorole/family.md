# /autorole family

Set family roles.

{% hint style="info" %}
For setup steps and examples, read [Auto Roles for Clan Role, Town Hall and League](../../../features/auto-role.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `family_leaders_role` | Role | Family leaders role (Leaders and Co-Leaders) |
| `family_role` | Role | Family role. |
| `exclusive_family_role` | Role | Exclusive family role (all linked accounts are in the family) |
| `guest_role` | Role | Guest role (not in the family) |
| `verified_role` | Role | Verified role (API token verified) |
| `account_linked_role` | Role | Account linked role (account linked but may not be verified) |
