# /capital contribution

Shows clan capital contribution of clan members.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `user` | User | Clan by @user mention or ID. |
| `week` | Text | The week to show contributions for.<details><summary>View Options</summary>`13 Nov, 2026`, `06 Nov, 2026`, `30 Oct, 2026`, `23 Oct, 2026`, `16 Oct, 2026`, `09 Oct, 2026`</details> |
