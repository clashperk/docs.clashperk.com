# /cwl

Clan War League stats for your clan: lineups, attacks, stars, rounds and group standings.

| Command | What it does |
|---------|--------------|
| [/cwl attacks](attacks.md) | Shows an overview of attacks for different CWL rounds. |
| [/cwl lineup](lineup.md) | Shows CWL lineup for a round (sorted by town hall and heroes). |
| [/cwl members](members.md) | Shows a list of all CWL participants. |
| [/cwl roster](roster.md) | CWL roster and town hall distribution. |
| [/cwl round](round.md) | CWL summary for the current round. |
| [/cwl stars](stars.md) | Shows CWL member ranking by stars. |
| [/cwl stats](stats.md) | Shows an overview of all CWL rounds and group standings. |
