# donations

Shows donations and donations received of clan members.

## Options

| Name | Description |
|------|-------------|
| `clan` | Clan tag or name or alias. |
| `user` | Donation history of a linked user. |
| `season` | The season to show donations for.<details><summary>View Options</summary>`Jul 2026`, `Jun 2026`, `May 2026`, `Apr 2026`, `Mar 2026`, `Feb 2026`, `Jan 2026`, `Dec 2025`, `Nov 2025`, `Oct 2025`, `Sep 2025`, `Aug 2025`, `Jul 2025`, `Jun 2025`, `May 2025`, `Apr 2025`, `Mar 2025`, `Feb 2025`</details> |
| `start_date` | Starting date (YYYY-MM-DD) |
| `end_date` | Ending date (YYYY-MM-DD) |
