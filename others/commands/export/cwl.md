# /export cwl

Export CWL stats to Excel.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases to filter clans. |
| `season` | Text | Retrieve data since the specified season.<details><summary>View Options</summary>`Nov 2026`, `Oct 2026`, `Sep 2026`, `Aug 2026`, `Jul 2026`, `Jun 16, 2026`, `Jun 2026`, `May 2026`, `Apr 2026`, `Mar 2026`, `Feb 2026`, `Jan 2026`, `Dec 2025`</details> |
| `lineup_only` | True or False | Export only the lineup. |
