# /autorole disable

Disable automatic role management for clan roles, town hall levels, or leagues.

{% hint style="info" %}
For setup steps and examples, read [Auto Roles for Clan Role, Town Hall and League](../../../features/auto-role.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `type` | Text | Type of roles to disable.<details><summary>View Options</summary>`Clan Roles`, `Town Hall Roles`, `Leagues Roles`, `Builder Hall Roles`, `Builder Leagues Roles`, `War Roles`, `End of Season Push Role`, `Family Leaders Role`, `Family Roles`, `Exclusive Family Role`, `Guest Role`, `Verified Role`, `Account Linked Role`</details> |
| `clans` | Text | Clan tags or aliases to filter clans. |
