# /export attack-log

Export war attack history.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases to filter clans. |
| `war_type` | Text | Regular or friendly wars (defaults to Regular)<details><summary>View Options</summary>`Regular`, `CWL`, `Friendly`</details> |
| `limit` | Whole number | Number of wars (Default: 25) |
