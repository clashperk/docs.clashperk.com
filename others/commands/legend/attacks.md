# /legend attacks

Shows per-day legend attacks for a clan.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases to filter clans. |
| `user` | User | Player by @user mention or ID. |
| `day` | Number | The league day. |

## Related commands

* [/legend days](days.md): Shows per-day legend attacks for a player.
* [/legend leaderboard](leaderboard.md): Shows legend leaderboard.
* [/legend stats](stats.md): Shows statistics of legend ranks and trophies.
