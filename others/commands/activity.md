# /activity

Shows a graph of hourly-active clan members.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases (Maximum 3) |
| `days` | Whole number | The number of days is displayed in the graph.<details><summary>View Options</summary>`1`, `3`, `7`, `15`, `30`</details> |
| `limit` | Whole number | Number of clans to show in the graph. |
| `timezone` | Text | Search timezone by city or country. (e.g. London, New York, Singapore, India, Sydney) |
