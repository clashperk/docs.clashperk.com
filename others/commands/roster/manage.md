# /roster manage

Add or remove users or change their group or roster.

{% hint style="info" %}
For setup steps and examples, read [CWL and War Rosters](../../../features/rosters/README.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `roster` | Text | Select a roster to manage |
| `action` | Text | Select an action to perform<details><summary>View Options</summary>`Add Players`, `Remove Players`, `Change Roster`, `Change Group`</details> |
| `player` | Text | Select a player to manage |
| `user` | User | Select a user to manage |
| `from_clan` | Text | Select a clan to add players from |
| `from_current_wars` | Text | Choose a clan to add players from the ongoing wars. |
| `target_group` | Text | Group of the user to move to |
| `target_roster` | Text | Roster of the user to move to |
