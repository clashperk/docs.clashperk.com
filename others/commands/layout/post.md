# /layout post

Post your village layout to showcase it to the community.

## Options

| Name | Type | Description |
|------|------|-------------|
| `screenshot` | File | Upload a screenshot showing your village layout. |
| `layout_link` | Text | Provide a shareable link to your layout. |
| `notes` | Text | Add custom notes or details about your layout. |

## Related commands

* [/layout config](config.md): Adjust settings related to layout posting and interactions.
