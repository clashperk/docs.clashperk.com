# /clan

Shows comprehensive overview of a clan.

## Options

| Name | Type | Description |
|------|------|-------------|
| `tag` | Text | Clan tag or name or alias. |
| `user` | User | Clan by @user mention or ID. |
| `by_player_tag` | Text | Get clan by a player tag. |
