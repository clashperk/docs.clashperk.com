# /remaining

Shows remaining or missed war hits of a clan.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `type` | Text | The type of remaining tasks to show.<details><summary>View Options</summary>`War Attacks`, `Clan Games`, `Capital Raids`, `Legend Attacks`</details> |
| `player` | Text | Remaining attacks of a player. |
| `user` | User | Remaining attacks of a linked user. |
| `war_id` | Text | Search by war ID. |
