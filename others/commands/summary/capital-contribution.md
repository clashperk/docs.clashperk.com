# /summary capital-contribution

Shows a summary of capital contributions.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tag or name or alias. |
| `season` | Text | Retrieve data for the specified season.<details><summary>View Options</summary>`Nov 2026`, `Oct 2026`, `Sep 2026`, `Aug 2026`, `Jul 2026`, `Jun 2026`, `May 2026`, `Apr 2026`, `Mar 2026`, `Feb 2026`, `Jan 2026`, `Dec 2025`, `Nov 2025`, `Oct 2025`, `Sep 2025`, `Aug 2025`, `Jul 2025`, `Jun 2025`</details> |
| `week` | Text | The week to show capital contributions for.<details><summary>View Options</summary>`13 Nov, 2026`, `06 Nov, 2026`, `30 Oct, 2026`, `23 Oct, 2026`, `16 Oct, 2026`, `09 Oct, 2026`</details> |
