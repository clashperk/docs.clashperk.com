# /layout config

Adjust settings related to layout posting and interactions.

## Options

| Name | Type | Description |
|------|------|-------------|
| `allow_voting` | True or False | Enable or disable voting on posted layouts. |
| `allow_tracking` | True or False | Enable or disable tracking of layout copies. |

## Related commands

* [/layout post](post.md): Post your village layout to showcase it to the community.
