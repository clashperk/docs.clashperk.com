# export cwl

Export CWL stats to Excel.

## Options

| Name | Description |
|------|-------------|
| `clans` | Clan tags or aliases to filter clans. |
| `season` | Retrieve data since the specified season.<details><summary>View Options</summary>`Jun 16, 2026`, `Jun 2026`, `May 2026`, `Apr 2026`, `Mar 2026`, `Feb 2026`, `Jan 2026`, `Dec 2025`, `Nov 2025`, `Oct 2025`, `Sep 2025`, `Aug 2025`, `Jul 2025`</details> |
| `wars` | Number of wars (Default: 25) |
| `lineup_only` | Export only the lineup. |
