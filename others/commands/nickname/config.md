# /nickname config

Configure automatic server nickname settings.

{% hint style="info" %}
For setup steps and examples, read [Nickname](../../../features/nickname.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `family_nickname_format` | Text | Set family nickname format (e.g. {CLAN} \| {ALIAS} \| {TH} \| {ROLE} \| {NAME}) |
| `non_family_nickname_format` | Text | Set non-family nickname format (e.g. {NAME} \| {TH}) |
| `change_nicknames` | Text | Whether to update nicknames automatically. |
| `account_preference_for_naming` | Text | Whether to use the default account or the best account in the family.<details><summary>View Options</summary>`Default Account`, `Best Account`, `Default or Best Account`</details> |
