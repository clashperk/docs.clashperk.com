# /ticket post

Post a ticket panel to the current channel.

{% hint style="info" %}
For setup steps and examples, read [Ticket System](../../../features/tickets.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `panel_name` | Text | Name of the panel to post |

## Related commands

* [/ticket add](add.md): Add a member to this ticket channel.
* [/ticket close](close.md): Close this ticket (generates transcript and deletes channel)
* [/ticket delete](delete.md): Delete a ticket panel.
* [/ticket info](info.md): View the configuration of a ticket panel.
* [/ticket reopen](reopen.md): Reopen a sleeping ticket (restore user access)
* [/ticket setup](setup.md): Create or edit a ticket panel configuration.
* [/ticket sleep](sleep.md): Put this ticket to sleep (remove user access, move to sleep category)
