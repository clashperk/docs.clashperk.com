# /summary missed-wars

Shows a summary of missed wars.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tag or name or alias. |
| `war_type` | Text | Regular, CWL or Friendly Wars (defaults to Regular)<details><summary>View Options</summary>`Regular`, `CWL`, `Friendly`, `Regular and CWL`</details> |
