# /export wars

Export War stats to Excel.

## Options

| Name | Type | Description |
|------|------|-------------|
| `clans` | Text | Clan tags or aliases to filter clans. |
| `war_type` | Text | Regular, CWL or Friendly Wars (defaults to Regular)<details><summary>View Options</summary>`Regular`, `Friendly`, `Regular and CWL`</details> |
| `start_date` | Text | Starting date (YYYY-MM-DD) |
| `end_date` | Text | Ending date (YYYY-MM-DD) |
| `limit` | Whole number | Number of wars (Default: 25) |
