# /setup clan

Manage clans on the server (link server, link channel, clan embed)

{% hint style="info" %}
For setup steps and examples, read [How to Set Up ClashPerk on Discord](../../../overview/getting-set-up.md).
{% endhint %}

## Options

| Name | Type | Description |
|------|------|-------------|
| `clan` | Text | Clan tag or name or alias. |
| `category` | Text | Category of the clan. (select from the menu or type your own) |
| `clan_channel` | Channel | Link the clan to a channel. |
| `unlink_clan_channel` | Channel | Unlink a channel from the clan. |
| `unlink_clan` | True or False | Unlink a clan from the server and remove all the features related to it. |
