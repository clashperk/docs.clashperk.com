# /capital

See clan capital contributions and raid weekend scores of your clan members.

| Command | What it does |
|---------|--------------|
| [/capital contribution](contribution.md) | Shows clan capital contribution of clan members. |
| [/capital raids](raids.md) | Shows raid weekend scores of clan members. |
